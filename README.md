# 蕴灵印（原型）

2D 俯视角**实时战斗** + **灵印收集合炼** + **时印回溯**。
主角：南宫亭瞳。

> 这是**独立于 `gu` 工程**的新项目。
> `gu\` 是教材（板块 1~8 的练习题、答案、排错手册都在那儿），这里是作业本，两边互不影响。

---

## 怎么跑

用 Godot 4.4 打开这个文件夹，或者命令行：

```bat
..\gu_tools\Godot_v4.4-stable_win64.exe --path .
```

## 怎么跑自测

```bat
..\gu_tools\Godot_v4.4-stable_win64_console.exe --headless --path . -- --selftest
```

看到 `失败 0 项`、退出码 0 就是好的。

> 自测会在开头打一堆 `ERROR: ... progress_dialog.cpp` —— **那是 Godot 自己的噪声**，
> 出现在 headless 模式下，和你的代码无关。看最后一行结论就行。

## 操作

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 移动 |
| **鼠标移动** | **决定朝向**（不是决定移动方向）|
| 鼠标左键 | 普攻，可按住连续出招 |

## 两条规矩

**① 每一行都要能解释。**
写不出来就去 `gu\` 看思路，然后**自己敲一遍**。不要复制 —— `gu\` 里的 `Game.gd` 有 1433 行，
搬一套读不懂的代码进来，等于以后每个 bug 都无法定位。

**② 一个键只能有一个含义。**
不要做"点按是一个功能、长按是另一个功能"的设计。见 [设计圣经.md](设计圣经.md) 的键位表。
