# 蕴灵印（原型）

2D 俯视角**实时战斗** + **灵印收集合炼** + **时印回溯**。
主角：南宫亭瞳。

> 这是**独立于 `gu` 工程**的新项目。
> `gu\` 是教材（板块 1~8 的练习题、答案、排错手册都在那儿），这里是作业本，两边互不影响。

---

## 怎么跑

用 Godot 4.7.2 打开这个文件夹，或者命令行：

```bat
..\gu_tools\Godot_v4.7.2-stable_win64.exe --path .
```

> `gu_tools` 里同时留着 4.4 的两个 exe —— 那是给 `gu\` 用的，**不要拿它开这个工程**。

## 怎么跑自测

```bat
..\gu_tools\Godot_v4.7.2-stable_win64_console.exe --headless --path . -- --selftest
```

看到 `失败 0 项`、退出码 0 就是好的。

> 自测会在开头打一堆 `ERROR: ... progress_dialog.cpp` —— **那是 Godot 自己的噪声**，
> 出现在 headless 模式下，和你的代码无关。看最后一行结论就行。

> ⚠️ **如果会话里不允许启动进程**（本机实测：任何子进程都报 `0xC0000142`），可以在**编辑器**里跑：
> 把 `res://.godot/run_selftest` 的内容写成 `1` → 从编辑器运行项目 → 自测跑完会自己退出，
> 结果在 `%APPDATA%\Godot\app_userdata\蕴灵印（原型）\logs\godot.log`（**每次运行覆盖**）。
> 跑完把内容改回 `0`。⚠️ 别读 MCP 的 game 日志缓冲：它只留前 200 行，会让人误判「自测中途崩了」。

> ⚠️ **编辑器开着本工程时，别直接改磁盘上的 `.gd`**：编辑器会把它的内存副本写回去，
> 把你外部的改动覆盖掉（本项目实测踩到过一次 —— `SealPanel.gd` 的改键被回退）。
> 所以**改完脚本必须重读文件确认**，或者先在编辑器里关掉对应的脚本页。

## 操作

> 键位**定义在 InputMap**（项目设置 → 输入映射），代码只认动作名，改键不用动代码：
> `move_up` `move_down` `move_left` `move_right`（WASD + 方向键）、`attack`（左键）、`seal_1` `seal_2` `seal_3`（1 2 3）。

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 移动 |
| **鼠标移动** | **决定朝向**（不是决定移动方向）|
| 鼠标左键 | 普攻（**灵力掌击**）：按住连续出招；**抬手 0.15 秒后判定**，掌风弧光先出来；不耗灵力、**不显化灵印**（所以用普攻是安全的）。伤害随境界成长（一阶 8 → 五阶 14）|
| `1` `2` `3` `4` | **使用灵印**：按一下 = 显化 + 立刻出招；再按一次 = 收回 |
| `E` | **交互**（按站的地方决定含义）：采集点旁 = 采集 · 锚点旁 + 灵力满 = **突破境界** · 商人旁 = **交易** |
| 走过去 | **自动拾取**掉落物（不用按键；背包满了东西会留在地上）|
| 走过去 | **强夺**灵师掉下的印（先进备用；**命窍满了就进背包** —— 收藏无上限）|
| `Tab` | **命窍面板**：左边**球形空窍**（已融合的印在灵气里浮动，球的大小 = 灵力容量）、中间印的详情、右边**背包**（未炼化的印 + 材料）。点背包里的印 → 点「炼化」；`Q` 或点「换上」从**备用 / 背包**里换印上场；底部三个按钮：**炼化**（花灵力把印炼到能用）/ **修炼**（灵力 → 修为）/ **突破**（修为满了就亮）|
| `F` | **开炉（合炼）**：选配方 → （可能出填料事件）→ 火候指针进绿区时按 `E` |
| 鼠标 | **交易面板里点一下选中、双击成交**（点哪一列就是买/卖哪一列）|
| `Shift` | **闪避**（0.28 秒滚 140px + 0.30 秒无敌）—— 需要**有一枚养熟的印** |
| `Space` | **冲刺**（1.2 秒加速）—— 需要**养熟一枚移速印**（流风印）|
| `R` | **结印**：起手后按数字键填两枚印 → 凑齐即放印诀（例：`R` `1` `3` = 爆炎）|
| `B` | **背包面板**：**左键点一下 = 选中 1 个（继续点每次 +1）· 右键点 = 全选（再点 = 取消）**，右边显示基本信息；然后 **`Q` 使用** / **`Delete` 丢弃**（丢弃要点两下确认）。`B` / `Esc` 关闭 |

**物品**：8 种材料（草木 / 矿石 / 兽材 / 触媒）+ 货币「灵石」。采集产材料，打怪掉材料与灵石，
走过去自动捡。背包按**容积**算：**草木 1 格 / 兽材 2 格 / 矿石 3 格 / 触媒 3 格**，总容积 **120**（M30.4）。
⭐ **灵石和灵印都不占容积** —— 灵印是收藏，想放多少放多少。同一件东西落在附近会**并成一堆**（数量相加，东西一件不少）。

**商人**（世界中心，走过去按 `E`）：**点一下选中 · 双击成交**；
**点左边那列就是买、点右边那列就是卖**（不用先切买卖）。
他的买列 = **货架（限量）+ 服务（不限量）**：还能花 10 灵石买 25 点灵力（灵力满了买不了）。
他卖 蕴灵草 6 / 兽骨 9 / 玄铁矿 17 / 地火芯 55 / 雷髓 60 灵石，
收你的东西只给**半价**（价差就是他的利润）。**货架一次性、卖了不补** —— 想买就得先出门赚。

**打击感**：打中会**停一下**（几十毫秒）、**震屏**、冒**伤害数字**（普攻白 / 灼烧橙 / 落雷紫 / 挨打红），
自己挨打还会**闪白**。手感参数全在 `GameData.JUICE` 一张表里 —— 觉得太轻或太重就改那张表。

**合炼（`F`）**：7 条配方，两种做法 —— **升阶**（主材 + 辅材 → 这枚印自己升一等，**不吃印**）与
**合成**（两枚印 + 辅材 → 全新一枚）。成功率 `50 + 辅材种数×5 + 灵魄×10 − 目标等级×10`，
**火候指针失误必失败**。做不了的配方会直接写出「还缺什么」。
⚠️ **本命印不能当合炼材料**。

**两条资源**：**灵力**（燃料：显化灵印 / **修炼**都用它，采集或**用灵石买**来补）→ **修为**（进度：
只能修炼涨、花不掉）→ 修为满 → **回锚点按 `E` 突破**。

**修炼**在 `Tab` 命窍界面里 —— 面板底部有进度条和「**修炼**」按钮（点它，或按 `E`）：
花 20 灵力换 20 修为。灵力不够或修为满了，按钮会变灰。

⚠️ **锚点机制已整体移除（M19）** —— 没有锚点、没有罗盘、没有 `E` 突破。
存档改为**每 10 分钟自动存一次 + 退出时存**。
世界里的**金色双环**，和屏幕上的**锚点罗盘**（在视野内套一圈标距离，在视野外贴边画箭头）。

⚠️ **突破是局内收获：不存档** —— 死了会**连同修为一起**退回上次钉锚（击败精英）时的境界。
HUD 上会写「未钉锚 · 死亡退回」提醒你。

**开局补满**：新局 / **读档** / 回溯 / 突破 —— 气血与灵力都会按**当前境界**的上限补满（不用省着用）。

**炼化 = 使用前提**：刚拿到的印**不能用**（不能显化、不给被动）；**炼满之后被动一律生效**（不分自己养的还是抢来的）。`Tab` 面板选中它 → 点「**炼化**」**花灵力**（M30.3 起不再消耗材料）
花 10 灵力涨 8%，炼满 100% 才算和命窍融合。强夺来的印是 0 —— 抢到了还得养。

⚠️ **回溯功能暂时移除（M28，等重新设计）** —— 死亡 = **回到出生点 + 世界退回上次存档 + 补满 + 写盘**。
代价很硬：丢的是**上次存档之后的一切**（10 分钟一存）。设计记录留在 [设计圣经.md](设计圣经.md) §4.4。
连死 3 次有保底（不再比上次退得更远），但**不会退过最后一个锚点**。
死亡界面会告诉你「回到多久前 + 为什么」。⚠️ 回溯会写回存档 —— 死了退出重进也没用。

**成长**：修为攒满 → **`Tab` 命窍 → 点「突破」**（地点不限；锚点机制已移除，`E` 不再管突破）→ 境界 +1
（炼气 → 筑基 → 金丹 → 元婴 → 化神），
气血 / 灵力上限 / 移速 / 命窍容量一起涨。**存档是每 10 分钟自动存 + 退出时存**（锚点机制已移除），
之后死亡就回到那个新锚点 —— 丢掉的是**两个锚点之间**的收获。

**敌人 13 个、4 种原型**，靠**形状**一眼分辨：
红**圆** 猛兽（追着你打）· 紫**方** 智谋（会绕后打你的显化灵印）· 青**菱** 灵师（远程，脚下画圈预警，身上带印）·
橙**三角** 蛮兽（画一条线蓄力，然后沿着那条线冲过来）。**金双环 = 精英**（血量 ×3、掉得更多）。
两种预警要你做的事**正好相反**：灵师的圈要**走出去**，蛮兽的线要**横着闪**。

**世界**：**1280×720** —— 相机 `zoom = 2`，所以屏幕上看到的和以前一样大，
但每个美术像素占 **2×2** 个屏幕像素（像素颗粒粗一倍）。四个分区各占一角 ——
草原（左上）/ 岩区（右上）/ 雷区（左下）/ 热区（右下），出生点在四区交界。
采集点 8 处（每区 2 处），敌人 13 个散布全图。

**灵印**：7 枚（**开局只有 2 枚**：灰烬 / 玄甲；惊雷 / 磐石 是**两只精英的必掉**；云雨 / 流风 / 辉光 在灵师身上，只能强夺）。
**抢来的印炼化度归零 —— 但炼满之后被动照常生效**（M20 定案，不再分自己养的还是抢来的）。
**命窍容量 6（境界给）、活跃 4 格**（`1`-`4`）。⭐ 容量限制的是**命窍里能放几枚**（活跃 + 备用），
**不限制收藏** —— 装不进命窍的印进**背包**，想放多少放多少（M29.5）。

**灵印有四种形态**（由「一次性 / 每秒」× 「放完即收 / 持续 / 定时」两条轴组合）：
灰烬印＝持续攻击、玄甲印＝持续防御、惊雷印＝一次性攻击、磐石印＝一次性防御。

**还没有的**：多区域与传送阵、战斗姿态 `Z X C`（定案**不做**）、NPC 自主成长、主菜单 / 暂停 / 设置、打包导出。
（这一行曾经写着「印诀 / 合炼 / 经济 / 存档」—— 那四项 M13 / M14 / M22 就做完了，文档落后了 10 个里程碑。）

> ⚠️ **抢来的印是 0 炼化度** —— 炼满 100% 才算「能用」（给被动、能显化）。
> 所以「抢到印」只是开始，「养印」才是那条循环。

## 和 DSH 的 Godot Creator 一起用

本工程装了 **Godot AI 3.1.5**（[addons/godot_ai](addons/godot_ai)），DSH 侧装了 `dsh-godot-ai@0.7.0`，两者配套。

1. 用 Godot **4.7.2** 打开本工程，并**保持编辑器开着** —— 关掉它，AI 就看不到场景树。
2. **项目 → 项目设置 → 插件** 里确认 **Godot AI** 已启用。
3. DSH 的 **设置 → Godot AI** 卡片里确认连接状态与目标项目。
4. 新建 DSH 会话时选 **Godot Creator** 模式。

> ✅ **2026-10 已回退到 3.1.5，这条规矩重新成立。**
> 之前真的漂移过一次：插件自更新把 `addons/godot_ai` 顶到了 **4.3.0**
> （`.godot_ai_update/` 和 `pending_self_update_event: success` 就是证据），
> DSH 侧也被 dock 的 Configure 改写成 `godot-ai==4.3.0` + 端口 8001/8002。
> 后果是**编辑器和我各连一个后端，永远握不上手**。
> 现在两边都回到 **3.1.5 / 8000 / 9500**；4.3.0 的整棵树留在
> `addons/.godot_ai_backup_4.3.0/`（点开头，Godot 不扫描），要翻随时能翻。
> ⚠️ **不要再让 4.x 进来**（3.1.5 里没有自动更新器了，但 AssetLib 仍会）。

**DSH 侧的两个环境前提**（换机器、或清了 uv 缓存后要重做）：

1. **`uvx` 必须在 PATH 上。** 插件靠 `uvx --from godot-ai==3.1.5 …` 拉起 MCP 后端。
   装法：`powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
2. **必须设 `UV_PYTHON=3.13`**：`setx UV_PYTHON 3.13`，然后重启 DSH。
   不设的话 uv 会挑最新的 CPython（3.15），而 `pyyaml` 在 3.15 上**没有预编译轮子**，
   uv 会退去源码编译，再因为缺 MSVC 构建工具而失败。

> 第 2 条是实测结论，不是猜测。不设时报的是：
> `Failed to build pyyaml==6.0.3 … Microsoft Visual C++ 14.0 or greater is required`。

## 两条规矩

**① 每一行都要能解释。**
写不出来就去 `gu\` 看思路，然后**自己敲一遍**。不要复制 —— `gu\` 里的 `Game.gd` 有 1433 行，
搬一套读不懂的代码进来，等于以后每个 bug 都无法定位。

**② 一个键只能有一个含义。**
不要做"点按是一个功能、长按是另一个功能"的设计。见 [设计圣经.md](设计圣经.md) 的键位表。
